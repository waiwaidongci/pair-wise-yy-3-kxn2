# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

环境变量：`PORT`（默认 3025）、`DB_PATH`（默认 `data/core-slices.json`）。

## 流程规则

- 切片按 取样 → 切割 → 研磨 → 染色 → 观察 顺序推进；跳步会被拒绝（409），响应里带当前可做的步骤。
- 记录「观察」时必须填写观察结论。
- 全部切片完成观察后才能交付；交付时记录交付时间，交付后不能退回、加切片或继续记步骤。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `server.js` | 入口：装配各层并启动服务 |
| `src/store.js` | 样本存取：台账 JSON 读写、串行写入 |
| `src/workflow.js` | 流程判断：步骤顺序、跳步校验、交付规则、状态推导 |
| `src/api.js` | 接口处理：路由、请求解析、错误响应 |
| `src/page.js` | 页面模板 |

新增或调整流程规则只改 `src/workflow.js`。
